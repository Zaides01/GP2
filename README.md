# Групповой проект №2 по предмету "Современные методы анализа данных и машинного обучения"

## Бизнес-Цель

В этом проекте мы исследуем возможности повышения вовлеченности пользователей в сообществах ВКонтакте через контент-стратегию. Вовлеченность пользователей измеряется с помощью таких метрик, как лайки, комментарии, репосты и просмотры видео и постов. Чтобы определить, какие факторы влияют на эти показатели, мы проведем анализ данных о постах на стене и видеозаписях, опубликованных в различных сообществах.

## Использование API ВКонтакте

В рамках работы над проектом мы использовали пять API-методов ВКонтакте для сбора данных о видео, постах, комментариях и сообществах. Эти методы помогли сформировать два датасета: один с данными о видеозаписях, другой — с постами на стене.

1. video.get — Получение информации о видеозаписях  
   Этот метод позволяет получить список видеозаписей и информации о них из сообщества или от пользователя.

2. video.getAlbums — Получение информации об альбомах с видео  
   Этот инструмент позволяет понять структуру видеоконтента в сообществе, как видео распределены в альбоме. В нашем случае мы использовали это, чтобы выгрузить информацию о проценте расформированных по альбомам видео

3. wall.get — Получение постов из сообщества  
   С его помощью мы выгрузили публикации со стены сообщества, включая текст, вложения, количество просмотров, лайков, репостов и комментариев. Эти данные использовались для анализа вовлеченности постов и их форматов.

4. video.getComments — Получение комментариев к видео  
   Этот метод предоставил информацию о содержании комментариев и активности пользователей, что способствовало анализу обсуждений в сообществе.

5. groups.getById — Получение информации о сообществе  
   Метод позволяет получить общую информацию о сообществе: количество подписчиков, описание, тематику и статус (открытое или закрытое). Эти данные использовались для анализа влияния параметров сообщества на вовлеченность контента.

## Веб-Скрапинг и парсинг

Мы также использовали веб-скрапинг и парсинг для сбора данных со страницы трендов сервиса ВК видео (отлчиается от Вконтакте!). В частности, мы применили Selenium для автоматизации процесса сбора данных. Этот инструмент позволил нам выгрузить информацию о популярных видеороликах, включая их названия, авторов (владельцев каналов) и количество просмотров. Использование Selenium значительно упростило сбор динамически загружаемого контента и сделало процесс эффективным.

Этот сбор данных помогает понять, какие видео находятся в топе, какие темы вызывают наибольший интерес у аудитории и как верификация канала влияет на популярность контента. В дальнейшем эти данные можно использовать для анализа трендов и формирования эффективной контент-стратегии.

Этот проект закладывает основу для более глубокого понимания взаимодействий пользователей с контентом и разработки стратегий, которые сделают ваши сообщества более активными и популярными.

## Описание датасетов:

После соединения всех собранных таблиц мы получили 2 датасета с не очень приятным форматом данных, который в рамках предобработки данных в EDA меняли

### Датасет df_video.csv (Контент: видео)

* id_x - Уникальный идентификатор видео - int
* owner_id - ID владельца видео (сообщества или пользователя) - int
* group_name - Название сообщества, в котором опубликовано видео - str
* title - Заголовок видео - str
* description_x - Описание видео - str
* duration - Длительность видео в секундах - int
* date - Дата публикации видео - datetime
* views - Количество просмотров видео - int
* comments - Количество комментариев под видео - int
* can_like - Возможность поставить лайк (булево значение) - bool
* can_repost - Возможность сделать репост (булево значение) - bool
* can_dislike - Возможность поставить дизлайк (булево значение) - bool
* is_pinned - Закреплено ли видео в группе - bool
* album_video_percent - Процентное соотношение видео в альбоме сообщества - float
* top_comment_text - Текст самого популярного комментария под видео - str
* id_y - Дублирующий идентификатор, связанный с группой (возможная ошибка дублирования) - int
* description_y - Описание сообщества, в котором опубликовано видео - str
* members_count - Количество подписчиков в сообществе - int
* activity - Тип активности в сообществе (например, “новости”, “развлечения”) - str
* status - Статус сообщества (например, открытое, закрытое) - str
* site - Сайт, указанный в информации о сообществе - str
* name - Название сообщества - str
* screen_name - Короткое название сообщества (URL-адрес) - str
* verified - Проверено ли сообщество (булево значение) - bool

### Датасет df_wall.csv (Контент: посты на стене)

* is_pinned - Закреплен ли пост - (0, 1)
* comments - Словаь информации о комменатриях, содержащий информацию о возможности комментировать, смотреть и количество комментариев
* marked_as_ads - Отмечен ли пост как рекламный - (0, 1)
* attachments - Вложения в посте (фото, видео, ссылки) - список
* date - Дата публикации поста - таймстемп
* from_id - ID автора поста - int
* id_x - Уникальный идентификатор поста - int
* likes - Информация по лайкам поста (аналогично комментарием)
* reactions - Информация о всех реакциях поста (словарь или список)
* owner_id - ID владельца поста - дублирует from_id
* post_source - Источник поста (например, API, web, mobile) - словарь с полем type
* reposts - Количество репостов поста - словарь, где количество лежит в поле count
* text - Текст поста - str
* views - Количество просмотров поста - словарь, где количество лежит в поле count
* donut_miniapp_url - Ссылка на мини-приложение, если пост связан с VK Donut - str
* check_sign - наличие подписи - bool
* id_y - Дублирующий идентификатор, связанный с группой - int
* description - Описание сообщества, в котором опубликован пост - str
* members_count - Количество подписчиков в сообществе - int
* activity - Рубрика сообщества - str
* status - Статус сообщества - str
* site - Сайт сообщества - str
* name - Название сообщества - str
* screen_name - Короткое название сообщества (URL-адрес) - str
* verified - Проверено ли сообщество (есть ли галочка) - (0, 1)
